# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately by email to
[alexander.s.ngai@gmail.com](mailto:alexander.s.ngai@gmail.com).
Do **not** open a public GitHub issue for security problems.

Include as much detail as you can: affected version or commit, reproduction
steps, and potential impact. You should receive an acknowledgment within a few
days, and a fix or mitigation will be coordinated with you before public
disclosure.

There is no bug bounty program at this time.
