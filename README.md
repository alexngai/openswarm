# swarm-coder

Multi-agent coding orchestration.

## Install

```sh
npm install swarm-coder
```

Or run the CLI without installing:

```sh
npx swarm-coder hello
```

## Usage

```ts
import { greet } from "swarm-coder";

console.log(greet("alex"));
```

## CLI

```sh
swarm-coder hello [name]
swarm-coder version
swarm-coder help
```
